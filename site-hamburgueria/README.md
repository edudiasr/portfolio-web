# Brasa Burger — Site para Hamburgueria

Landing page de hamburgueria smash com cardápio filtrável, carrinho e pedido via WhatsApp.

> Projeto fictício para portfólio. Endereço: Centro de Joinville, SC.

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-hamburgueria/`

## Objetivo

Demonstrar um site gastronômico de alta conversão — visual “fogo”, cardápio interativo e fluxo de pedido sem backend.

## Diferenciais técnicos

- Fotos reais no cardápio (mapeadas pelos nomes dos arquivos)
- Hero com foto de ambiente + card do Brasa Duplo
- Filtro de cardápio + carrinho → WhatsApp
- Popup **Anuncie conosco** (abre após alguns segundos + botão lateral)
- Contato: WhatsApp `(47) 99207-2891` · Centro de Joinville, SC
