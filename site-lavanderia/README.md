# Ciclo — Lavanderia

Lavanderia em Joinville: self-service e full service, calculadora por kg, status de pedido demo e agendamento de coleta via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-lavanderia/`

## Diferenciais

- Visual deep slate + aqua + sky (Lexend + IBM Plex Sans)
- Preloader tambor, vapor ambient, máquina hero com timer e bolhas
- Serviços filtráveis (self / full / especiais)
- Calculadora kg × urgência → WhatsApp
- Tracker de status demo (recebido → pronto)
- Agendamento de coleta com janela de horário
- Cursor custom, tilt 3D, botões magnéticos
