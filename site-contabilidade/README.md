# Nexo Contábil — Contabilidade

Escritório contábil em Joinville: abertura, regimes, folha, checklist de documentos e proposta via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-contabilidade/`

- Dashboard fiscal com sparkline ao vivo e prazos em dias
- Simulador MEI / Simples / Lucro Presumido
- Checklist de abertura com anel de progresso → WhatsApp
- Cursor custom, tilt 3D, botões magnéticos, barra de leitura
