# Aegis Corretora — Seguros

Corretora de seguros em Joinville: auto, vida, residencial, empresarial e saúde, com simulador de cotação, diagnóstico de cobertura e atendimento via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: https://edudiasr.github.io/portfolio-web/site-seguros/

## Diferenciais

- Visual ink navy `#070b14` + trust blue `#4d8bff` + soft mint `#5eead4` (Space Grotesk + Manrope)
- Preloader com escudo pulsante, mesh ambient e painel de proteção no hero
- Produtos filtráveis (auto, vida, residencial, empresarial, saúde)
- Simulador de cotação: tipo + idade + valor → faixa estimada + WhatsApp
- Quiz de 3 perguntas → checklist de cobertura no WhatsApp
- Cursor custom, progress bar, reveal, tilt 3D, botões magnéticos
- Equipe: Eduardo Dias (corretor) · Eduarda Dias (atendimento)
- FAQ, depoimentos, formulário e float WhatsApp
- Responsivo + `prefers-reduced-motion`
