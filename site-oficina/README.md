# Torque Auto — Oficina Mecânica

Oficina e auto center em Joinville: diagnóstico por sintomas, serviços filtráveis, estimativa de orçamento e chamado via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-oficina/`

## Diferenciais

- Visual asphalt + âmbar signal + cyan HUD (Orbitron + Sora)
- Preloader gauge, grid ambient, scanlines, ticker de serviços
- Cursor custom, tilt 3D, botões magnéticos, barra de progresso
- HUD ao vivo (relógio, boxes, leituras OBD)
- Checklist de sintomas → mensagem WhatsApp
- Calculadora de faixa de orçamento (serviço × urgência × ano)
- Equipe: Eduardo Dias · Eduarda Dias
