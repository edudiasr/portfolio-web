## 🛠️ Stack

- **HTML5** semântico, acessível e otimizado para SEO
- **CSS3** com design tokens, Grid, Flexbox e microanimações
- **JavaScript vanilla** — sem dependências, sem build, abre direto no navegador

---

## ✨ O que este portfólio demonstra

- Layouts profissionais (não genéricos)
- Responsividade impecável (mobile-first)
- UX pensada para conversão (WhatsApp, CTAs, prova social)
- Código organizado, legível e pronto para cliente real
- Recursos avançados: dark mode, scroll reveal, carrosséis, before/after, formulários
