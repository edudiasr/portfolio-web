Validador de types.xml

Confere a economia do servidor antes do restart e mostra a linha de cada problema. O arquivo é lido aqui no seu navegador, não vai pra servidor nenhum.

Solte aqui o types.xml

Pode soltar junto o cfglimitsdefinition.xml e o cfglimitsdefinitionuser.xml pra conferir os nomes de usage, value, tag e category. Dá pra mandar vários types de uma vez (os dos mods, por exemplo).

      O que ele confere (22 regras)

      Erros

      • E001 XML quebrado (tag sem fechar, -- dentro de comentário, & solto…)
      • E002 raiz não é <types>
      • E003 <type> sem name
      • E004 item duplicado (sem diferenciar maiúscula, igual o jogo)
      • E005 tag repetida no mesmo item
      • E006 número que não é número
      • E007 valor negativo
      • E008 min maior que nominal (com nominal > 0)
      • E009 quantmin/quantmax fora de -1 ou 0–100
      • E010 quantmin maior que quantmax
      • E011 flag diferente de 0 ou 1
      • E012 usage/value/tag/category sem name
      • E013 nome que não existe no cfglimitsdefinition

      Avisos

      • W001 tag desconhecida
      • W002 falta tag padrão (nominal, lifetime, flags…)
      • W003 nominal > 0 sem lugar pra nascer
      • W004 só um entre quantmin e quantmax é -1
      • W005 usage/value/tag repetida
      • W006 atributo estranho no <flags>
      • W007 <flags> faltando atributo
      • W008 coisa fora de <type>
      • W009 usage/value que não existe, mas o item tem outra válida
