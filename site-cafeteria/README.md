# Pulp — Café & Açaí

Cafeteria em Joinville: cardápio filtrável, montagem de bowl com preço ao vivo, carrinho e pedido via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-cafeteria/`

## Diferenciais

- Visual cocoa + açaí berry + lime (Bricolage Grotesque + DM Sans)
- Preloader dripping, partículas de berry no canvas, noise ambient
- Hero bowl 3D-ish com toppings animados + pill por horário do dia
- **Bowl builder**: base × tamanho × até 5 toppings · preview + preço
- Carrinho drawer com total e checkout WhatsApp
- Combos, cartão fidelidade animado, toast de add
- Cursor custom, tilt, magnéticos, barra de progresso
- Equipe: Eduardo Dias · Eduarda Dias
