# Base — Construtora & Reformas

Construtora em Joinville: residencial, comercial e reforma, com estimativa por m², cronograma interativo e briefing via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-construtora/`

## Diferenciais

- Visual concreto + laranja de segurança (Archivo + Work Sans)
- Preloader guindaste, grid ambient, canteiro hero com avanço ao vivo
- Serviços filtráveis + portfólio com % de obra
- Estimativa tipo × m² × complexidade → WhatsApp
- Cronograma por fases clicáveis
- Checklist pré-obra
- Cursor custom, tilt 3D, botões magnéticos
