# Amora Pet — Clínica & Pet Shop

Site para clínica veterinária e pet shop em Joinville: serviços com filtro, planos, equipe e agendamento via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-petshop/`

## Diferenciais

- Visual coral + mint com foto real do espaço (fundo desfocado + showcase)
- Glassmorphism, cursor custom, tilt 3D, botões magnéticos
- Agenda ao vivo, filtros animados, marquee e parallax suave
- Formulário com nome do pet → WhatsApp
- Equipe: Dra. Eduarda Dias · Eduardo Dias
