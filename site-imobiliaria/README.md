# Vértice Imóveis — Site Imobiliário

Site para imobiliária em Joinville: busca com filtros, cards de imóveis, bairros, processo e conversão via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-imobiliaria/`

## Diferenciais

- Filtros por tipo, negócio (venda/aluguel) e faixa de preço
- Cards com CTA “Quero visitar” → WhatsApp com o imóvel selecionado
- Identidade charcoal + sage (Fraunces + Figtree)
- Contadores, scroll reveal, formulário de atendimento
