# Ónix Barbearia — Landing Page

Landing page premium para barbearia masculina: agendamento via WhatsApp, tabela de preços, equipe, galeria e prova social.

> Projeto fictício para portfólio. Visual e textos ilustrativos.

## Preview local

Abra `index.html` no navegador (ou Live Server).

Demo online (após publicar):  
`https://edudiasr.github.io/portfolio-web/landing-barbearia/`

## Objetivo

Mostrar um site comercial com identidade forte (carvão + latão), tipografia editorial e fluxo de conversão direto para WhatsApp — contraste visual com o projeto tech CtrlTec.

## Tecnologias

- HTML5 semântico + SEO / Open Graph
- CSS3 (design tokens, Grid, animações, marquee)
- JavaScript vanilla (menu, reveal, contadores, formulário → WhatsApp)
