# Echo Idiomas — Escola de Idiomas

Escola em Joinville: cursos filtráveis, teste rápido CEFR, chat de aula ao vivo e reserva de experimental via WhatsApp.

> Projeto fictício para portfólio · Centro de Joinville, SC

## Demo

Local: abra `index.html`  
Online: `https://edudiasr.github.io/portfolio-web/site-idiomas/`

- Console de aula com chat EN/ES/DE e waveform ao vivo
- Quiz de nível CEFR (3 perguntas)
- Montagem de aula experimental → WhatsApp
- Cursor custom, tilt 3D, botões magnéticos, barra de leitura
